Backup & cloud storage

This ledger already autosaves to cloud storage tied to your Claude account — that's on by default, nothing to set up.

A quick honest note: this page can't sign in to your iCloud account directly — browser apps like this one aren't given that kind of access to Apple accounts. To put a copy in iCloud Drive (or Google Drive, Dropbox, etc.) as well, export a file below and choose that folder in your browser's save dialog. Import brings a file back in, on this device or another — imported entries land in the table below and can be edited or deleted just like anything you typed in by hand.

Passkey lock

Adds a lock screen asking for a passkey before this page opens — useful if you publish or share the link. Being straight with you: this is a light deterrent, not real encryption. It's stored as plain text in your cloud storage and anyone who can view this page's code can bypass it, so don't rely on it to protect sensitive data. If you publish this page, each visitor already gets their own private, separate data automatically — the lock just keeps casual visitors from opening the app at all.
